This page presents all key figures from the analysis of DMM’s VQR 2020–2024 results. Each figure is generated from the embedded R code (click “Code” to expand). Source data: ANVUR institutional report for the Università degli Studi di Padova, Tables 2.1–2.4.

Area-Level Comparisons

DMM contributes evaluated products in two disciplinary areas: Area 05 (Biology) and Area 06 (Medicine). The following figures compare DMM against other Padova departments active in each area, across all three R indicators.

Area 05 — Biology

Code 
plot_area <- function(area_code, titolo) {
  d <- area_df |> filter(area == area_code)
  ord <- d |> filter(indicatore == "R1_2") |> arrange(desc(R)) |> pull(sigla)
  ord <- union(ord, unique(d$sigla))
  d <- d |> mutate(
    sigla = factor(sigla, levels = ord),
    grp = paste0(ifelse(is_dmm, "DMM_", "ALT_"), indicatore)
  )
  pal <- c(
    DMM_R1 = unname(RED["R1"]), DMM_R2 = unname(RED["R2"]),
    DMM_R1_2 = unname(RED["R1_2"]),
    ALT_R1 = unname(GRAY["R1"]), ALT_R2 = unname(GRAY["R2"]),
    ALT_R1_2 = unname(GRAY["R1_2"])
  )
  ggplot(d, aes(sigla, R, group = indicatore, fill = grp)) +
    geom_col(position = position_dodge(width = 0.8), width = 0.75) +
    geom_hline(yintercept = 1, linetype = "dashed", color = REF_LINE) +
    geom_text(aes(label = it_num(R)),
              position = position_dodge(width = 0.8), vjust = -0.4, size = 2.6) +
    scale_fill_manual(values = pal, guide = "none") +
    labs(title = titolo, x = NULL,
         y = "R indicator (> 1 = above national average)") +
    theme_minimal(base_size = 12) +
    theme(
      panel.grid.major.x = element_blank(),
      axis.text.x = element_text(
        face = ifelse(levels(d$sigla) == "DMM", "bold", "plain")
      )
    )
}
plot_area("5", "Area 05 — Biology: DMM vs peer departments")

In Area 05, DMM’s R1 (1.12) is above the national average, though not the highest among Padova biology departments — DIMED leads with 1.31 (albeit from a small base of only 10 products). DMM’s R2 (1.12) and R1_2 (1.12) are consistent: above-average but mid-range within this peer group. DiBio, the largest biology department, outperforms on R2 (1.19) and R1_2 (1.15).

make_rank_panel <- function(col, color, strip_title) {
  d <- ird_df |>
    transmute(R = .data[[col]], is_dmm,
              lbl_fct = fct_reorder(sigla, R),
              fill = ifelse(is_dmm, color, "#B0B0B0"))
  ggplot(d, aes(x = R, y = lbl_fct, fill = fill)) +
    geom_col(width = 0.78) +
    geom_text(
      aes(x = -0.04, y = lbl_fct, label = as.character(lbl_fct),
          color = is_dmm, fontface = ifelse(is_dmm, "bold", "plain")),
      hjust = 1, size = 2.2) +
    geom_text(aes(label = it_num(R)), hjust = -0.08, size = 2.0, color = INK) +
    geom_vline(xintercept = 1, linetype = "dashed", color = REF_LINE, linewidth = 0.3) +
    scale_fill_identity() +
    scale_color_manual(values = c("FALSE" = "gray30", "TRUE" = "#9B0014"), guide = "none") +
    scale_x_continuous(breaks = seq(0, 1.4, 0.2), limits = c(-0.05, 1.52),
                       labels = function(x) ifelse(x < 0, "", it_num(x)),
                       expand = expansion(mult = c(0, 0.02))) +
    coord_cartesian(clip = "off") +
    labs(title = strip_title, x = NULL, y = NULL) +
    theme_minimal(base_size = 9.5) +
    theme(
      plot.title = element_text(color = "#9B0014", face = "bold",
                                size = 8.5, lineheight = 1.2),
      axis.text.y = element_blank(), axis.ticks.y = element_blank(),
      panel.grid.major.y = element_blank(), panel.grid.minor = element_blank(),
      plot.margin = margin(t = 4, r = 8, b = 4, l = 55)
    )
}

This figure reveals the central tension in the VQR results: DMM has one of the highest R1_2 values (green bar), yet ranks in the bottom third on IRD. This is because IRD = H × R, and H is proportional to department size. Departments like DFA (387 expected products) or FISPPA (352) achieve high IRD even with modest R values, simply because they are large.

The scatter plot makes the structural relationship explicit: IRD is almost entirely determined by department size, with quality (colour) providing only modest variation around the trend line. DMM sits well below the trend line for its size, but this is because it is a smaller department.

ImportantImplications for benchmarking

Using IRD as the sole or primary metric for internal benchmarking disadvantages small departments regardless of their research quality. DMM ranks 1st on R1 and 4th on R1_2 among all 32 Padova departments, yet 21st on IRD. If funding or prestige decisions rely heavily on IRD, high-quality small departments are structurally penalised.

A fairer comparison would use R (quality per product) alongside IRD, or present IRD residuals after accounting for department size.

| R1 | 1.26 | 1st | Best tenured-staff quality in the university |
| R2 | 1.11 | 6th | Above average for new recruits |
| R1_2 | 1.15 | 4th | Top quartile overall |

The gap between R1 (1.26) and R2 (1.11) suggests that DMM's tenured faculty produce higher-quality research than its more recently recruited staff — or alternatively, that newly recruited researchers have not yet had sufficient time to build a mature publication portfolio within the evaluation window.

::: {.callout-important}
## Implications for benchmarking

Using IRD as the sole or primary metric for internal benchmarking disadvantages small departments regardless of their research quality. DMM ranks 1st on R1 and 4th on R1_2 among all 32 Padova departments, yet 21st on IRD. If funding or prestige decisions rely heavily on IRD, high-quality small departments are structurally penalised.

A fairer comparison would use R (quality per product) alongside IRD, or present IRD residuals after accounting for department size.
:::
